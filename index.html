최근 365일 급등 직전 패턴 유사도 검색

최근 365일 동안 하루 안에 시가 대비 고가가 +10% 이상 오른 사례를 조사합니다. 해당 날짜의 15분봉에서 시가 대비 +3%를 처음 돌파한 봉을 급등 시작 지점으로 정의하고, 시작 6시간·3시간·1시간 전의 24시간 가격·거래대금 패턴을 각각 추출해 현재 코인과 비교합니다. 유사도 순위를 계산한 뒤 현재 흐름을 상승 전환 징후·방향 미확인·하락세 지속으로 나눠 각 그룹 최대 10종을 표시합니다.

365일 급등 사례 · 실제 상승 시작 시점 탐색 · 1/3/6시간 전 비교분석을 시작해 주세요.

아직 분석 전입니다. 버튼을 눌러 급등 시작 1·3·6시간 전 패턴과 현재 코인을 비교하세요.

⚠ 첫 실행은 과거 자료를 수집하므로 시간이 걸립니다. 과거 패턴 DB는 최초 수집 후 기기에 계속 보관하며, 이후 분석은 저장된 DB를 재사용합니다. 재수집은 별도 버튼을 눌렀을 때만 진행합니다. 브라우저 사이트 데이터 삭제·기기 변경 시에는 다시 수집해야 합니다. 1년치 일봉은 종목당 여러 차례 나눠 조회하므로 첫 실행은 오래 걸릴 수 있습니다. 거래대금 상위 최대 100종의 과거 사례와 현재 최대 45종을 비교합니다. 형태 유사도는 급등 확률이 아니며 투자 권유가 아닙니다.

거래지원 종료 예정 코인 · 오전 8~11시 분석

거래지원 종료 예정 종목을 별도 관리하고 지정한 날짜의 업비트 실제 15분봉으로 오전 9시 전후 가격과 거래대금 변화를 확인합니다. 오전 9시 급등을 가정하지 않으며, 매수 추천 기능이 아닙니다.

종목과 날짜를 선택한 뒤 분석을 시작해 주세요.
공식 공지 확인 후 종목 추가

자동 공지 수집은 아직 지원하지 않습니다. 종료 예정 종목을 직접 등록하고 공식 공지 링크로 확인할 수 있습니다. 등록 정보는 이 브라우저에 저장됩니다.

기본 등록: BLAST · 거래지원 종료 2026-10-26 12:00 KST. 거래지원 종료 전후 급등은 가격 급락과 매도 불능 위험이 큽니다. 거래지원 종료 이후에는 과거 분봉 API 조회가 제한될 수 있습니다. 이 기능은 해당 날짜의 시간대별 실제 변화만 보여주며 급등 확률을 예측하지 않습니다.
