# UPBIT SIGNAL LAB (PWA prototype)

개인용 설치형 웹앱. 업비트 KRW 마켓 시세 조회, 24시간 변동률·거래대금 기반 **탐색용 임시 점수**, 관심 코인 로컬 저장, 단일 코인 60분봉 200개 기반 **교육용 간이 검증** 포함.

## 실행

정적 HTTPS 호스팅(GitHub Pages, Cloudflare Pages 등)에 모든 파일을 업로드하면 됩니다. 로컬 개발 시 `python -m http.server 8080` 실행 후 `http://localhost:8080` 접속. PWA 설치는 HTTPS 또는 localhost 환경에서 지원됩니다. Android Chrome 메뉴에서 설치 또는 홈 화면 추가를 선택하세요.

## 중요 제한

- 현재 버전은 **12개월 전체 종목 백테스트, 통계적으로 검증된 급등 예측 모델, 24시간 서버 감시, 백그라운드 푸시 알림**을 제공하지 않습니다.
- 탐색 점수는 임시 계산식으로, 예측 확률이나 투자 신호가 아닙니다.
- 간이 검증은 최대 200개 60분봉을 사용하며, 미래 고가 도달 여부만 측정합니다. 체결가능성, 슬리피지, 수수료, 시장 편향, 독립적인 검증기간은 반영되지 않습니다.
- 업비트 공개 API 브라우저 호출은 환경에 따라 CORS/호출 제한 문제가 발생할 수 있습니다. 안정적 운영 시 서버 프록시와 데이터베이스를 권장합니다.
- 24시간 감시를 원한다면 상시 실행 백엔드와 푸시 알림 인프라가 추가로 필요합니다.
