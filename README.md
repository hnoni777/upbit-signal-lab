# UPBIT SIGNAL LAB · v58

개인용 원화마켓 초기 움직임 연구 앱. 모든 현재 KRW 거래쌍의 닫힌 1분봉을 같은 기준 시각으로 분석합니다.

## v54 상세 분석

모든 현재 원화마켓의 1분봉을 조회한 다음, 최초 조건을 충족한 후보와 최근 30분 이내의 이전 후보를 다시 조회합니다. 후보별 상세 봉 기준 시각을 표시합니다. 전체 시장 조회와 후보 재확인의 기준 시각은 다를 수 있습니다. 재확인 실패는 해당 카드에 표시하며 신규 평가 기록을 생성하지 않습니다. 이전 후보가 최초 조건을 벗어나면 약화 상태로 추적하고 새 신호로 집계하지 않습니다.

최근 1·3·5·15·30분 수익률, 최근 3분 거래 지속, 실제 거래 발생 분 수, 9/20 EMA, 20분 VWAP, ATR, 직전 돌파 구간과 최근 저점·고점, 같은 시각 BTC 대비 상대 수익률을 계산합니다. 이는 최근 60분 자료의 파생 지표이며 네이티브 3·5·15분봉의 완성된 봉 패턴 검증은 아닙니다. EMA는 최근 60분 종가로 초기화합니다. 실제 매수/매도 체결 주체나 호가의 매집 여부는 판정하지 않습니다.

화면은 점수 대신 흐름 유지 / 눌림 관찰 / 초기 흔적 관찰 / 신호 약화를 표시합니다. 고정 규칙은 아직 검증 전 가설입니다. 거래 배수가 큰 이유가 작은 평소 거래대금일 수 있으면 경고합니다. 무거래 보완 봉을 실제 거래 발생으로 세지 않습니다. 알려진 달러 연동 토큰(USDT, USDC 등)은 전체 조회하되 급등 후보에서는 제외합니다. 목록 기반 제외로 모든 연동 자산을 자동 판별하는 것은 아닙니다.

기존 `totals`와 기존 기록은 보존합니다. 신규 조건은 `strategyVersion:54`, `detailTotals`로 분리하여 평가합니다. 과거 기록을 새 조건의 검증 성과로 재사용하지 않습니다. 상세 후보 자료가 추가되지만 5분 예약 실행·실행 지연·초 단위 감시 부재라는 한계는 동일합니다. 가격 구간은 관측값이며 매수·손절 지시가 아닙니다.

## 순서 탐지

업비트가 생략하는 무거래 분은 시작 가격을 확인할 수 있는 1분봉 API 응답에서만 직전 종가·거래대금 0으로 보완합니다. 조회 실패를 무거래로 취급하지 않습니다.

연속된 60분 데이터에서 처음 45분을 기준으로 삼습니다. 다음 10분 동안 거래대금 평균 1.5배 이상, 증가가 4봉 이상 지속, 후반 저점 유지, 양봉 또는 보합 5봉 이상이면 선행 흔적으로 봅니다. 마지막 5분에서 소폭 돌파와 유지, 거래대금 2배 이상을 확인합니다. 조기 관심과 돌파 확인을 별도로 표시합니다. 최근 15분 거래대금 1천만원 미만, 이미 5% 이상 상승, 봉 누락은 제외합니다. 기준 45분 가격 범위는 3% 이하입니다.

이 수치는 검증 전 가설입니다. 점수는 신호 순위용이며 확률이나 세력 매집의 증거가 아닙니다. 1분봉에는 실제 매수/매도 체결 주체·횟수·호가 이력이 없습니다. 기존 96개 압축 패턴은 보존하지만 새 신호 점수에 혼합하지 않습니다. 기존 Python 학습은 저가를 max로 계산하고 브라우저는 min으로 계산한 불일치가 있으므로 그 모델을 새 신호 검증에 사용하지 않습니다.

## 신호 이후 관찰

서버 분석 완료 후 다음 1분봉 시가를 가상 진입으로 사용합니다. 사용자가 화면을 연 시점의 진입가나 실제 주문 체결가가 아닙니다. 30분 동안 +3% 순목표(비용 가정 0.3% 포함 가격 +3.3%)와 가격 -2% 손절선의 선후를 판정합니다. 같은 봉에서 양쪽 도달은 순서 불명으로 기록하고 성공에 포함하지 않습니다. 시간 종료도 별도로 기록합니다. 비용 가정은 실제 체결비용 측정치가 아닙니다.

기본 화면은 서버 누적 기록을 표시합니다(상위 5개에 들지 않은 신호도 포함). 같은 종목·단계는 30분 중복 제한이 있습니다. 서버의 다음 실행에서 평가하며, 지연으로 최근 200봉에 평가 구간이 없으면 그 과거 구간을 별도 조회합니다. API 오류가 난 종목의 대기 기록은 유지합니다. 자료가 실제로 부족하면 누락으로 처리하고 성공·실패 분모에서 제외합니다. 누적 집계는 계속 보존하며 완료된 개별 기록은 최근 1,000건, 미평가 기록은 별도로 보존합니다.

## 서버 감시

`.github/workflows/server-scan.yml`이 표준 GitHub-hosted Ubuntu 서버에서 `scripts/server_scan.cjs`를 실행합니다. 현재 v54.2에서는 cron 대신 작업 후속 호출로 약 5분 간격을 유지하지만 대기열 때문에 실행 시각은 보장하지 않습니다. 지연·누락·서비스 제한이 생길 수 있고 초 단위 실시간 감시는 아닙니다. 스캔 중복 실행은 직렬화합니다. 12분 이상 실행은 종료하며 이전 정상 결과를 보존합니다.

`server-data` 브랜치의 `data/server-state.json`에 분석 결과·대기 기록·누적 결과를 저장합니다. 화면을 닫거나 휴대폰을 꺼도 서버가 실행됩니다. GitHub Pages는 GitHub 파일 API로 최신 저장 결과를 5분 간격으로 읽어 표시하며 서버 완료 시각이 7분 이상 오래됐으면 지연을 표시합니다. 화면 자동 갱신을 꺼도 서버 예약은 계속 실행됩니다. API 대규모 오류는 결과를 덮어쓰지 않습니다. 조회한 원화마켓 목록이 비어도 마지막 정상 자료를 보존합니다.

서버 수집은 업비트 공식 API `https://api.upbit.com/v1`에 직접 연결합니다. Cloudflare 중계 요청은 사용하지 않습니다. 3개 동시 요청과 시작 간격 180ms 제한을 적용합니다. 2년치 학습 자료는 재수집하지 않습니다. 표준 실행기를 쓰는 공개 저장소 방식이며 추가 유료 호스팅을 신청하지 않습니다. 푸시 알림과 실제 자동매매는 없습니다. 서버 기록에는 공개 시장 자료와 탐지 결과만 저장하고, 기기의 기존 개인 기록은 업로드하지 않습니다.

웹 브라우저의 별도 Origin 호출 제한 때문에 기기 직접 분석 버튼은 제거했습니다. 앱은 서버 결과만 읽습니다. 서버 수동 실행은 Actions의 Background market scanner에서 Run workflow를 사용합니다.

## v54.1 갱신 진단

같은 서버 완료 시각을 다시 읽으면 새 분석 결과 없음으로 표시합니다. 서버 자료 나이를 30초마다 갱신하며, 마지막 조회 시각을 분석 완료 시각과 구분합니다. `lastTrigger`와 `lastScheduledAt`은 실행 이벤트를 저장합니다. 최초 schedule 이벤트가 실제 완료되기 전에는 예약 자동 실행이 확인되지 않았다고 표시합니다. 파일 수정에 따른 push 실행 성공은 예약 실행의 검증이 아닙니다. 예약 구문은 표준 5분 표현으로 재설정했으며 실행 기록과 새 결과로 실제 동작 여부를 확인해야 합니다.

## v54.2 자동 이어실행

GitHub cron 실행이 관찰되지 않아 cron을 제거했습니다. 작업이 결과를 저장한 후 시작 시각 기준 약 300초가 되면 workflow_dispatch로 후속 작업을 시작합니다. 배포 직후에는 연결 검증을 위해 한 번 즉시 이어실행합니다. 신규 배포 또는 수동 실행은 기존 작업을 취소하여 중복 루프를 방지합니다. 자동 후속 작업은 앞 작업의 정리가 끝날 때까지 대기하여 정상 이어실행이 취소로 표시되지 않게 합니다. 실패 시 마지막 정상 결과를 보존하고 다음 실행을 시도합니다. API 또는 실행 권한 장애로 후속 작업 호출 자체가 실패하면 중단될 수 있으며, 화면 자료 나이로 확인해야 합니다. 실행기 대기열 때문에 정확한 5분은 보장하지 않습니다.

중지는 .github/server-control.json의 enabled를 false로 변경하면 됩니다. 실행 시작과 다음 호출 직전에 확인합니다. intervalSeconds는 300초입니다. 인증은 GitHub가 작업에 일시적으로 제공하는 GITHUB_TOKEN만 사용하며 사용자 토큰을 코드에 저장하지 않습니다. 표준 공개 저장소 실행기 설정을 유지합니다. 단순 예약보다 대기 중 실행 시간 사용량은 늘어나며 비공개 저장소로 변경하면 요금 조건을 다시 검토해야 합니다. lastAutonomousAt은 chained 입력으로 실제 실행·저장이 성공한 시각입니다.

서버 완료 시각과 개별 상세 봉이 각각 7분 이내이고 재조회가 성공한 자료만 사용합니다. 흐름 유지 또는 눌림 관찰, 거래 지속, 실제 거래 발생 10/15분 이상, 평소 분당 거래대금 10만원 이상, 양의 15분 수익률과 음수가 아닌 3분 수익률, EMA 상승 정렬, 20분 VWAP 위, BTC 대비 상대 수익률 0 이상, ATR 이격 3 이하, 고점 대비 되밀림 1.5% 이하를 요구합니다. 달러 연동 자산·기존 조건 이탈 추적·재확인 실패는 제외합니다. 가격 구간은 실제 매수/손절 지시가 아닙니다. 자료 조회가 실패하거나 오래되면 추천을 숨깁니다. UI가 30초마다 자료 나이를 다시 평가하므로 갱신을 꺼도 오래된 추천은 보류됩니다.

흐름 유지 상태를 눌림보다 먼저, 이후 기존 구조 품질과 종목 코드 순으로 정렬하고 최대 3개만 표시합니다. 조건을 충족하는 종목이 없으면 제외 사유별 건수와 추천 보류를 표시합니다. 성공률 개선이나 검증된 투자 성과로 표시하지 않습니다.

## v58 평가 완료 결과 즉시 학습·적용
