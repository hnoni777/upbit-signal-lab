# UPBIT SIGNAL LAB · v51.1

개인용 원화마켓 초기 움직임 연구 앱. 모든 현재 KRW 거래쌍의 닫힌 1분봉을 같은 기준 시각으로 분석합니다.

## 순서 탐지

업비트가 생략하는 무거래 분은 시작 가격을 확인할 수 있는 1분봉 API 응답에서만 직전 종가·거래대금 0으로 보완합니다. 조회 실패를 무거래로 취급하지 않습니다.

연속된 60분 데이터에서 처음 45분을 기준으로 삼습니다. 다음 10분 동안 거래대금 평균 1.5배 이상, 증가가 4봉 이상 지속, 후반 저점 유지, 양봉 또는 보합 5봉 이상이면 선행 흔적으로 봅니다. 마지막 5분에서 소폭 돌파와 유지, 거래대금 2배 이상을 확인합니다. 조기 관심과 돌파 확인을 별도로 표시합니다. 최근 15분 거래대금 1천만원 미만, 이미 5% 이상 상승, 봉 누락은 제외합니다. 기준 45분 가격 범위는 3% 이하입니다.

이 수치는 검증 전 가설입니다. 점수는 신호 순위용이며 확률이나 세력 매집의 증거가 아닙니다. 1분봉에는 실제 매수/매도 체결 주체·횟수·호가 이력이 없습니다. 기존 96개 압축 패턴은 보존하지만 새 신호 점수에 혼합하지 않습니다. 기존 Python 학습은 저가를 max로 계산하고 브라우저는 min으로 계산한 불일치가 있으므로 그 모델을 새 신호 검증에 사용하지 않습니다.

## 신호 이후 관찰

표시 후 다음 1분봉 시가를 가상 진입으로 사용합니다. 30분 동안 +3% 순목표(비용 가정 0.3% 포함 가격 +3.3%)와 가격 -2% 손절선의 선후를 판정합니다. 같은 봉에서 양쪽 도달은 순서 불명으로 기록하고 성공에 포함하지 않습니다. 시간 종료도 별도로 기록합니다. 비용 가정은 실제 체결비용 측정치가 아닙니다.

모든 감지 신호를 기기에 저장합니다(화면 상위 5개에 들지 않은 신호도 포함). 같은 종목·단계는 30분 중복 제한이 있습니다. 다음 스캔 때 최근 200개 1분봉으로 판정합니다. 평가 구간이 없으면 누락이며 성공·실패 분모에서 제외합니다. 오래 화면을 닫으면 누락될 수 있습니다. 기록은 최근 최대 약 1,000건이며 개인정보 전송은 없습니다. 자동 갱신은 기본 꺼짐이며 사용자가 켜면 완료 후 1분 간격으로 반복합니다. 백그라운드 서버 감시나 푸시 알림은 없습니다.

## 검증

`node --test tests/sequence.test.cjs`

`node scripts/replay_sequence.cjs candles.json report.json`

입력은 `{ "KRW-BTC": [업비트 1분봉 응답, ...], ... }`입니다. 시간순 마지막 20% 구간에서 고정 규칙과 거래대금 증가율 순위 기준을 비교합니다. 두 방식 모두 같은 유효 데이터·유동성·이미 상승 제외 기준을 씁니다. 같은 시각에 최소 5종목이 있는 구간만 평가합니다. 미래 봉은 신호 입력에 사용하지 않으며 같은 종목의 중복 진입을 30분 제한합니다. 비교 방식은 신호 수가 달라 건수와 적중률을 함께 보아야 합니다. 비용은 고정 가정이며 호가·유동성별 실제 체결은 재현하지 않습니다. 합산 결과는 포트폴리오 수익률이 아닙니다. 홀드아웃 결과를 보고 규칙을 조정하면 새 미사용 평가 구간이 필요합니다.

v51의 실제 시장 과거 재생은 아직 실행하지 않았습니다. 기존 15분봉 압축 모델로 1분봉 순서를 검증할 수 없습니다. 기능 테스트 성공과 투자 성능 검증은 별개입니다.

## 실행

GitHub Pages에서 index.html, app.js, sequence.js 및 기존 스타일·아이콘을 제공합니다. API는 기존 Cloudflare Worker를 사용합니다. 모든 종목을 최대 3개 요청 병렬로 조회하며 요청 시작은 160ms 이상 간격으로 제한합니다. 종목 수와 API 응답 속도에 따라 시간이 걸릴 수 있습니다. 기준 시각이 3분 이상 지난 분석은 지연 표시하고 신규 기록을 제한합니다. API 실패와 봉 누락은 조건 미충족과 구분합니다.
